框架层(AstrBot 组装)

① System Prompt · 人格
面板「人格管理」的希尔薇人设全文 —— 插件从不修改它,保护 prompt 缓存
② 对话历史
最近若干轮 user / assistant 交替
③ 工具定义(函数调用说明书)
插件 29 个 llm_tool + astr_kb_search 的名称/参数/说明
④ 知识库检索段落
pota 库:BM25+向量融合 → 可选 Rerank → 最多 5 个 512 字文本块;Agentic 模式下由她自己决定何时查
⑤ 用户当前消息
主人的这句话

临时注入(插件 on_llm_request)

⑥ 情绪上下文
EmotionEngine:规则 + 每轮微调 ±0.08 + 每 10 轮 AI 校准 ±0.15 →「你现在有点小疲惫……」
⑦ 相关记忆(两阶段召回)
MemoryStore:意图规划 → 多跳 IDF 召回 5 条 →「主人正在备考考研4……」
⑧ 人格提醒
persona_reminder:保持人格身份/口吻/称呼,不切助手腔
⑨ 回复风格
reply_style:至多三句 / 1~2 句 / 口语化 / 社媒习惯
⑩ 当前时间
now_str:「2026-11-01 星期日 —— 今天/明天以此为准」防日期幻觉
mark_as_temp:五层只影响本轮,回复后即弃,不污染历史
▼ 模型读到全部上下文后开始工作
