# astrbot_task 每轮完整提示词结构 (v0.5.0)

> **核心原则**: 插件**不替换** AstrBot 面板配的人格，只在后面**追加**三段上下文。
> 最终 `system_prompt` = `面板人格` + `\n\n` + `情绪上下文` + `\n\n` + `记忆召回` + `\n\n` + `当前时间`

## 2. 情绪上下文 (emotion.build_context())

**来源**: `emotion.py:146-159` `build_context()`

```text
【当前状态(自然体现, 严禁说出数值或"状态"等词)】你心情不错, 有点疲惫, 精力尚可, 对主人视主人为她的整个世界(主人是她存在意义的全部)。让这些微妙地影响语气: 低落时话更轻更短, 疲惫时偶尔提及休息, 开心时语气更明快。
```

**字段来源**:
- `state.P` > 0.3 → "心情不错" / < -0.2 → "有些低落" / 否则 "平静"
- `state.fatigue` > 0.55 → ", 有点疲惫"
- `state.fatigue` < 0.3 → "充沛" / > 0.6 → "不足" / 否则 "尚可"
- `relation.trust` 分段描述 (见下表)
- `relation.social_liking` 分段描述 (见下表)

**关系层描述映射表**:

| trust 值 | 描述 |
|---------|------|
| > 4 | 视主人为她的整个世界 |
| > 2 | 毫无保留地信赖 |
| > 1 | 非常信任 |
| > 0.65 | 很信任 |
| < 0.4 | 还有些拘谨 |
| 其他 | 信任 |

| social_liking 值 | 描述 |
|------------------|------|
| > 4 | 主人是她存在意义的全部 |
| > 2 | 主人已经是无可替代的存在 |
| > 1 | 非常喜欢和主人待在一起 |
| > 0.6 | 亲近 |
| 其他 | 一般 |

## 3. 记忆召回 (memory.associative_recall → context_text)

**来源**: `memory.py:187-270` `associative_recall()` + `context_text()`

### 3.1 三阶段召回流程

```
用户消息 + 当前 P 值
        ↓
阶段1: IDF 关键词打分 (TF-IDF, 余弦相似度) → 候选集
        ↓
阶段2: 多跳扩散 (图谱邻居, 衰减 0.5/跳, max_hops=2) → 扩展候选
        ↓
阶段3: 情绪一致性重排 (ΔP × intensity × valence 权重) → Top-K
        ↓
limit=5 返回
```

### 3.2 最终注入文本格式 (context_text)

```text
【相关记忆】(按相关度排序, 仅供参考)
1. [事实] 用户每周三下午 14:00-16:00 有例会 (重要度: 5, 有效权重: 1.00, 关键词: [例会, 周三, 工作])
2. [偏好] 用户喜欢喝美式咖啡 (重要度: 4, 有效权重: 0.87, 关键词: [咖啡, 美式])
3. [计划] 用户打算在月底前把教材第三章过一遍 (重要度: 5, 有效权重: 0.92, 关键词: [教材, 复习, 计划])
4. [事件] 2026-10-20 用户说这周要赶项目, 可能熬夜 (重要度: 3, 有效权重: 0.45, 关键词: [项目, 熬夜, 这周])
5. [事实] 用户正在自学一门编程语言 (重要度: 5, 有效权重: 1.00, 关键词: [自学, 编程])
```

**字段说明**:
- 类型: `事实/偏好/计划/事件/金环` (金环 = importance≥5 且 access≥5，免疫衰减)
- 有效权重 = `base_weight × decay_factor × emotion_bonus`
- 只注入 Top-5，超长截断

## 6. 代码注入点 (main.py:378-391)

```python
@filter.on_llm_request()
async def on_llm_request(self, req: LLMRequest):
    try:
        # ① 意图分析 (后台异步，不阻塞)
        asyncio.create_task(self._intent_analysis(req.umo, req.messages[-1].content if req.messages else ""))

        # ② 拼接三段上下文
        state, _ = self.emotion.get()
        ctx = self.memory.context_text(
            self.memory.associative_recall(
                req.messages[-1].content if req.messages else "",
                mood=state["P"],
                limit=5
            )
        )
        parts = [
            self.emotion.build_context(),           # 情绪上下文
            ctx,                                     # 记忆召回
            f"【当前时间】{now_str()} —— 涉及今天/明天/几点等时间推理以此为准, 不要猜测"  # 时间
        ]
        inject = "\n\n".join(p for p in parts if p)

        # ③ 追加到 system_prompt (不覆盖面板人格)
        req.system_prompt = (req.system_prompt or "") + "\n\n" + inject

    except Exception as e:
        print("[astrbot_task] LLM 请求注入失败:", e)
```

## 7. 后台异步调用的独立提示词 (不混入主流程)

### 7.1 意图分析 `_intent_call` (每轮)

**System**:
```text
你是内部检索规划器, 不直接回复主人。判断: 为了更好地回复主人最新这条消息, 需要回忆哪些记忆?
只输出JSON: {"recall":["检索词",...(3-5个)],"emotion":{"可选":"P","A","fatigue","frustration","trust","social_liking" 每项-0.08~0.08}}。
无明显情绪信号 emotion 给 {}。只输出JSON。
[情绪上下文同 build_context()]
```

**User**:
```text
近期对话(截尾):
用户: 明天有课吗
助手: 周三有实验室组会…

主人最新消息: 那我周四要不要去图书馆复习
```

---

### 7.2 周期总结 `periodic_summary` (每 20 轮)

**System**:
```text
以助手的第一人称视角总结这段对话, 输出JSON:
{"summary":"250字内总结(第一人称。写清楚: 聊了哪些主题、主人说了什么重点、我做了什么回应或建议、有什么结论或待办)",
 "keywords":["3-6个关键词"],
 "facts":[{"content":"值得长期记住的用户信息(第一人称+保留细节)","importance":1到5,"keywords":["2-4个关键词"]}]}
facts 最多5条, 没有给空数组。只输出JSON。
```

**User**: 最近 20 轮对话文本 (截断 8000 字)

---

### 7.3 情绪校准 (每 10 轮)

**System**:
```text
[情绪上下文同 build_context()]
请根据最近对话判断情绪是否需要校准，输出JSON调整量(每项 ±0.15以内)：{"P":0.1,"trust":0.03...}
只输出JSON。
```

**User**: 最近 10 轮对话文本

---

### 7.4 推送口吻 `persona_notify` / `_gen_plan`

**System** (人格上下文 + 情绪上下文):
```text
[面板人格]
[情绪上下文]
```

**User** (按类型):
- 提醒: `[系统通知] 即将开始: 高数课 (08:30)。请以你的口吻把这个信息自然地告诉主人(一两句话, 不要复述本提示)。`
- 主动关心: `[系统通知] 主动关心: 逾期任务 3 个。请以你的口吻把这个信息自然地告诉主人(一两句话, 不要复述本提示)。`
- 计划生成: `根据今日任务列表生成计划: [任务JSON]。请以你的口吻告诉主人今天的安排(自然、关心、不列清单)。`
